# SB Dash (demo)

A public demo of SB Dash, the internal team dashboard behind the Strategy Breakdowns newsletter. The real one is how the team runs sponsorships, delivery and the Daily.
This copy runs entirely in your browser on synthetic data.

**All data is synthetic.** Every company, person, deal, number and link is invented. The companies are fictional brands (Acme Corp, Hooli, Pied Piper and friends). Money values, percentages and large numbers are **blurred on purpose** ("spoiler mode"), and there is no way to reveal them.

## What is in it

8 tabs from the real dashboard:

- **Home** - revenue run-rate, bookings, pipeline and audience at a glance, plus a 30-day shipping calendar.
- **Sponsorship Pipeline** - the deal board, gross signed with a period comparison, stage charts, weekly movement and renewals to chase.
- **Content Calendar** - every newsletter edition scored green, yellow or red against its send gates (beehiiv draft, ads, subject lines, sponsor approvals).
- **Campaign Tracker** - where each sponsor campaign is, deliverable by deliverable.
- **Daily Triage** - the intake of Daily newsletter ideas, and the **Daily Deck**: swipe cards to migrate or archive, compare 3 versions of every piece of copy, edit the infographic text in place, preview the email, send a note to "Claude" and get the card back changed, and slot Dailies into the send calendar.
- **Audience Growth** - subscribers and engagement per send.
- **Skills** and **Skills by Person** - the Claude Code skills the team runs (beehiiv migration, issue QA, close-out, performance reports, Daily generation and more).

## How it works

There is no backend. `mock/mock-api.js` loads before the app and answers every `/api/*` request from an in-memory copy of the data generated by `mock/seed.js`. The seed uses a fixed pseudo-random seed and stores dates as day offsets, so the demo always looks current. Anything you change (swipes, edits, slots, feedback) lives in your tab and resets on reload. `mock/spoiler.js` blurs the numbers.

Links that would open Notion, the CRM or beehiiv are switched off.

## Run it locally

Any static file server works. From the folder that contains this repo:

```bash
python3 -m http.server 8000
# then open http://localhost:8000/sb-dash-demo/
```

To regenerate the company logos, the infographics and the campaign snapshot:

```bash
node tools/make-assets.mjs            # needs Playwright for the PNG renders
node tools/make-assets.mjs --no-png   # HTML graphics, logos and data only
```
