# SB Dash (demo)

A public demo of SB Dash, the internal team dashboard behind the Strategy Breakdowns newsletter. The real one is how the team runs sponsorships, delivery and the Daily.
This copy runs entirely in your browser on synthetic data.

**All data is synthetic.** Every company, person, deal, number and link is invented. The companies are fictional brands (Acme Corp, Hooli, Pied Piper and friends). Money values, percentages and large numbers are **blurred on purpose** ("spoiler mode"), and there is no way to reveal them.

## What is in it

Every tab from the real dashboard, 18 in all. Some are shown in full, some have their numbers or names blurred, and a few are hidden behind a blur entirely:

- **Home** - revenue run-rate, bookings, pipeline and audience at a glance, plus a 30-day shipping calendar.
- **Big 3** - each person's 3 focus tasks for the week, and what happened to last week's.
- **Sponsorship Pipeline** - the deal board, gross signed with a period comparison, stage charts, weekly movement and renewals to chase.
- **Bookings Forecast** - revenue already booked, by window and by month.
- **Revenue Calculator** - hidden.
- **StrategyHub Funnel** - landing pages, beehiiv entry-point automations, the welcome offer and purchases. Every number is blurred.
- **Content Calendar** - every newsletter edition scored green, yellow or red against its send gates (beehiiv draft, ads, subject lines, sponsor approvals).
- **Deliverables Calendar** - every sponsor deliverable, week by week.
- **Campaign Tracker** - where each sponsor campaign is, deliverable by deliverable.
- **Automation Watchdog** - a daily check that the automations did what they should have.
- **Daily Triage** - the research run behind the Daily: topics filed, where they come from, which were approved for drafting and how many drafts were migrated to beehiiv.
- **Audience Growth** - subscribers and engagement per send. Every number and edition name is blurred.
- **Social Performance** - hidden.
- **Shipping Leaderboard** - who ships changes to the team repo, people and automation alike. Shown in full.
- **Skills** - hidden.
- **Skills by Person** - who built and edits each Claude Code skill, as an interactive map. Skill names and descriptions are blurred.
- **Repo File Tree** and **Skill Suggestions** - hidden.

## How it works

There is no backend. `mock/mock-api.js` loads before the app and answers every `/api/*` request from an in-memory copy of the data generated by `mock/seed.js`. The seed uses a fixed pseudo-random seed and stores dates as day offsets, so the demo always looks current. `mock/spoiler.js` blurs the numbers. Hidden tabs keep their layout under a blur, and the data under them is placeholder filler, so removing the blur shows nothing either.

Links that would open Notion, the CRM or beehiiv are switched off.

## Run it locally

Any static file server works. From the folder that contains this repo:

```bash
python3 -m http.server 8000
# then open http://localhost:8000/sb-dash-demo/
```

To regenerate the company logos and the campaign and social snapshots:

```bash
node tools/make-assets.mjs
```
